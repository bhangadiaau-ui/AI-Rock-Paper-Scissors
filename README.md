# AI Rock Paper Scissors ✋🤖

A hand-gesture based Rock Paper Scissors game built using:
- Python
- OpenCV
- MediaPipe

This project uses a webcam and MediaPipe hand tracking to detect
hand gestures in real time and play Rock–Paper–Scissors against an AI.

---

## Features
- Real-time hand gesture recognition
- AI opponent with random choice logic
- Score tracking for player and AI
- Timer-based round system
- Webcam-based gameplay

---

## Requirements
- Python 3.8+
- Webcam
