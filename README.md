# AI Rock Paper Scissors ✋🤖

A real-time Rock Paper Scissors game using hand gesture recognition with OpenCV and MediaPipe.

## Features
- AI Mode (Player vs Computer)
- Multiplayer Mode (2 players using one webcam)
- Countdown animation
- Gesture stability (anti-flicker)
- Fair gameplay (locked moves)
- Score tracking

## Technologies Used
- Python
- OpenCV
- MediaPipe

## How to Run
```bash
pip install opencv-python mediapipe==0.10.5
python rock_paper_scissors.py
